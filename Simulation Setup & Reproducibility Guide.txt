# REPRODUCIBILITY AND EXECUTION INSTRUCTIONS: SIMORGH FRAMEWORK

This document details the software dependencies and instructions required to execute and validate 
the SIMORGH routing framework simulation testbed.

## 1. Environment & Prerequisites
- **Operating System:** Ubuntu 22.04 LTS or macOS Sonoma
- **Python Version:** Python 3.10+
- **Mobility Simulator:** Eclipse SUMO (Simulation of Urban MObility) version 1.18.0+
- **Traffic Generator:** D-ITG (Distributed Internet Traffic Generator) v2.8.1
